Methodology & data quality

What was included, what was changed, and how to interpret the results.

Source files

ev_market_train.csv: 200,000 rows. ev_market_test.csv: 100,000 rows. Both source files contain 37 columns.

The training split is used for dashboard summaries. One duplicate training vehicle ID was removed, leaving 199,999 analysis records. The 100,000 test records are stored separately.

Cleaning rules

  • Trim whitespace in categorical columns and normalize empty values.
  • Convert numeric fields to numeric types.
  • Impute missing numeric values with the training-set median; missing annual sales values are set to zero.
  • Replace missing categorical values with Unknown.
  • Clip impossible negative performance/cost measures to zero and ratings to 0–5.

Interpretation caution

The supplied CSVs have not been independently verified as official market data. Figures describe the provided records. Annual sales sums are not verified market totals, and no predictive model performance is claimed.

Reproducibility

Rebuild the database and aggregates using python src/build_data.py. Run the site with python app.py. See the documentation folder for SQL, Tableau setup, performance testing, and the video script.
